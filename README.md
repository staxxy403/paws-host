VPS хостинг на базе [Incus](https://github.com/zabbly/incus) с панелью управления в Telegram-боте.

### **🛠️ Roadmap**

**Core:**
- [ ] Проектирование структуры БД
- [ ] Слой API над Incus REST API (выдача VM, биллинг)
- [ ] Базовая преднастройка VM через cloud-init
- [ ] Логи аудита для всех действий юзеров

**UI:**
- [ ] Telegram-бот как панель управления
- [ ] i18n (RU/EN)
- [ ] Админ-панель (web)

**Billing:**
- [ ] Жизненный цикл VM при неоплате (остановка..удаление)
- [ ] Баланс, транзации и выставление инвойсов
- [ ] Аддоны (disk, cpu, ram, snapshots)

**DevOps:**
- [ ] Ansible-плейбук для подготовки серверов
- [ ] Автоматические бэкапы и снепшоты VM
- [ ] Мониторинг ресурсов каждой VM и гипервизора
- [ ] Ограничение канала одного инстанса
- [ ] Алертинг при проблемах с серверами

А остальное, когда будут деньги...
